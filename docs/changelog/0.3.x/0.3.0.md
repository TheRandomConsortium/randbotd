# randbotd v0.3.0 Release Changelog

## 📡 Multi-Hop P2P Gossip Engine & Overlay Network Specification Refinements

- **`NET-02` Multi-Hop P2P Gossip Router (`src/net/gossip.rs`, `src/net/router.rs`)**:
  - Implemented `GossipMessage` with `RBd1` magic bytes framing, 32-byte `SHA-256` Message ID, `Ed25519` originator signature verification, and TTL-bounded relaying (`DEFAULT_GOSSIP_TTL = 8`).
  - Added in-memory `seen_cache` deduplication to prevent routing loops across multi-hop P2P topologies.
  - Implemented `AddressAnnouncementPayload` allowing nodes to broadcast signed dynamic IP updates (`new_address`, `timestamp`, `is_seed`).

- **2-Way Handshake Protocol & Peer Keepalives (`src/net/handshake.rs`, `src/net/router.rs`)**:
  - Implemented 2-way handshake exchange (`HandshakeInit` `RBd1` $\rightarrow$ `HandshakeResponse` `RBr1`) with Ed25519 signature verification and X25519 ephemeral key exchange.
  - Added periodic 30-second background ping keepalives (`PAYLOAD_TYPE_PING`) to maintain UDP NAT hole-punching.
  - Built dead peer garbage collection (`prune_inactive_peers(90)`), automatically pruning peers inactive for > 90 seconds (3 missed ping cycles).

- **UPnP IGD Port Mapping & NAT Self-Diagnosis (`src/net/nat.rs`)**:
  - Integrated automatic UDP port forwarding via `igd` crate for P2P listening port (`43210`).
  - Added self-diagnosis reachability reporter notifying operators if firewall/router manual port forwarding is required.

- **Persistent Peer Phonebook & Genesis Seed Resolution (`src/net/phonebook.rs`)**:
  - Built JSON peer phonebook storage (`peers.json`) maintaining `pubkey_hex`, `address`, `last_seen`, `self_declared_seed`, and `verified_seed`.
  - Added default genesis seed domain `therandomconsortium.org:43210` with automatic dynamic socket address resolution.
  - Explicitly separated `self_declared_seed` claims from `verified_seed` status, deferring dynamic seed promotion to Web-of-Trust behavioral ponderation (`REP-03`).

- **Overlay Privacy & Anti-Entropy Sync Specification Refinements ([MANIFESTO.md](file:///home/mreugenej7/git/randbotd/MANIFESTO.md), [FUNCTIONALITIES.md](file:///home/mreugenej7/git/randbotd/FUNCTIONALITIES.md))**:
  - Formulated **Lean Daemon Philosophy** (proxy delegation over embedded privacy runtimes).
  - Defined `NET-07` (`do_not_advertise_ip`) and `NET-08` (Overlay Peer Discovery & Phonebook Sharing).
  - Formulated **Node-Bound Integer + Linked Hash Hybrid Log** (`seq`, `prev_hash`) and self-terminating ping-pong range intersect protocol for `NET-05`.
