# randbotd v1.0.1 Release Changelog

### 🔑 Deterministic Gutenberg Mnemonic Seed Derivation & Security Fix

Version 1.0.1 fixes a critical key recovery flaw where node identity keypairs were previously generated from unseeded thread CSPRNG while a Gutenberg 24-word phrase was generated and discarded. In v1.0.1, node key generation is atomically bound to the Gutenberg 256-bit entropy phrase, ensuring deterministic key recovery via `--recover`.

---

## 🚀 Key Improvements & Cryptographic Fixes

### 1. Deterministic Node Identity Key Derivation (`src/main.rs`, `src/crypto/identity.rs`)
- **Fixed Mnemonic Decoupling Flaw**: Fixed a critical flaw where `NodeIdentity::generate()` previously used unseeded `rand::thread_rng()` while `GutenbergMnemonic::generate_256bit_phrase()` was generated and thrown away.
- **Atomic Gutenberg Binding**: Key generation (`--force-new` or initial startup) now drills Project Gutenberg for 256-bit entropy *first*, deriving the Ed25519 keypair directly from the mnemonic seed.
- **Guaranteed `--recover` Roundtrip**: Running `randbotd --recover "<gutenberg_phrase>"` deterministically reconstructs the exact same Ed25519 keypair, public key, and Node ID every time.
- **Removed Obsolete Unseeded Generator**: Removed `NodeIdentity::generate()`. All persistent identity creation strictly requires Gutenberg seed derivation (`NodeIdentity::from_seed_and_role`).

### 2. Dual-Layer CA Accountability & Market Distrust Mechanics (`MANIFESTO.md`, `FUNCTIONALITIES.md`)
- **`REP-08` User CA Flagging Engine (`Signal / Flag CA`)**: Added specification for PoW-backed, weighted user flags against CAs that decay exponentially over time, triggering `NOTIF-01` domain owner alerts when crossing network threshold $T_{\text{warn}}$.
- **`REP-09` Market Signal of Distrust**: Added specification for domain owners executing early renewals tagged `reason: DistrustSignal`. Sacrificing remaining TTL + ACME fees replaces PoW with economic burn, issuing permanent non-decaying UTW strikes to rogue CAs.
- **`CA-09` Cryptographic Key Rotation Engine**: Added CA remediation primitive enabling CAs to publish signed `KeyRotationProof` payloads to reset standing flags.

### 3. Do-Not-Match (DNM) CA Exclusion Filter (`FUNCTIONALITIES.md`)
- **`ACME-08` (`--dnm <CA_ID>`)**: Added client flag allowing domain owners to exclude distrusted or low-TTL CAs during early renewal. If free CA pools in that band are exhausted, Fair-Band defaults back to the existing CA unless the owner raises their price ceiling (`account_price_ceiling`), driving organic demand for paid CA tiers.

### 4. Decentralized ISO/IEC 9834-8 / ITU-T X.667 UUID OID Specification (`MANIFESTO.md`, `FUNCTIONALITIES.md`)
- **`CA-10` Critical Custom X.509 OID Engine**: Embedded custom X.509 extension marked `critical = TRUE` under ITU-T X.667 decentralized UUID OID `2.25.332006307751889903095271628869501346770.1.1` (derived from UUID `f9c616c7-8e4d-4f84-a32e-596b5ada63d2`).
- **Voluntary Opt-In & Anti-Free-Riding**: Un-augmented legacy browsers automatically reject native certs, ensuring zero forced adoption or free-riding without explicit user opt-in (extension/proxy).
- **Genesis Provenance Archive**: Committed PGP-signed root UUID genesis proof in [`docs/genesis_oid.asc`](file:///home/mreugenej7/git/randbotd/docs/genesis_oid.asc), with author public key verification instructed via `the.consortium.randºm`.

### 5. 3-Step Escrow-less Smart Contract Settlement (`FUNCTIONALITIES.md`, `MANIFESTO.md`)
- **`PAY-03` Monero `tx_key` Proofs**: Detailed 3-step state machine (`ContractConstitution` $\rightarrow$ `CertEmission` $\rightarrow$ `TxKeyProof`). Fraudulent local clients/CAs modifying local binaries are isolated into a solipsistic parallel universe rejected by P2P consensus.
