# randbotd v0.2.1 Release Changelog

## 🛡️ Rigorous CSPRNG Entropy Engine & Pure Gutenberg Mnemonic Refinements

- **Shannon Entropy Calculation Engine**:
  - Refactored `src/crypto/gutenberg.rs` to replace raw string byte length counting with exact Shannon entropy summation ($H = \log_2(N_{\text{unique}})$ bits).
  - Deduplicates word pools (`words.dedup()`) per Gutenberg book to establish the exact unique vocabulary size $N_{\text{unique}}$.
  - Guarantees accumulated entropy strictly reaches or exceeds $256.0 \text{ bits}$.

- **Elimination of Static Fallbacks**:
  - Removed low-entropy hardcoded static word arrays from the Gutenberg driller.
  - Generates recovery phrases strictly from live Project Gutenberg books retrieved dynamically over HTTP.

- **OS CSPRNG & Rejection Sampling (`rand_dice`)**:
  - Upgraded random index sampling to use Linux Kernel CSPRNG (`rand::rngs::OsRng`) with `gen_range(0..max)` uniform rejection sampling.
  - Completely eliminates modulo bias and PRNG predictability.

- **CLI Key Management & Mnemonic UX**:
  - Terminal-only mnemonic output with clear security warning header: `⚠️ SAVE THIS MOTHERFUCKER OR YOU WON'T BE ABLE TO RECOVER YOUR NODE!`.
  - Added `--recover "<mnemonic_phrase>"` CLI argument to restore node keys directly from space-separated word phrases via SHA-256 seed derivation.
  - Added `--force-new` CLI argument to destroy/replace local identity keyfiles cleanly.

## 🧪 Verification Summary
- **Automated Unit Tests**: All 5 unit tests (`test_magic_bytes_valid`, `test_magic_bytes_invalid`, `test_handshake_init_roundtrip`, `test_identity_encrypted_roundtrip`, `test_gutenberg_mnemonic_roundtrip`) passed cleanly.
- **Manual Verification**: Verified live Gutenberg phrase generation, OS CSPRNG sampling, and phrase-to-seed recovery roundtrips.
