# randbotd v0.1.0 Release Changelog

## Phase 0 Initial Infrastructure & Debian Daemon Setup

- **Project Cleanliness Enforcement**: Ported `check_cleanliness.sh` tidiness script from `juanita-banana` and integrated automatic check execution into `build.rs`.
- **Main Executable**: Initialized Rust binary printing `"Random Consortium's Certificate Bot Daemon (randbotd) running"`.
- **Debian Daemon Packaging**: Created `debian/randbotd.service` systemd unit file, `postinst` script (creating system user `randbotd`, state directory `/var/lib/randbotd`, config directory `/etc/randbotd`), and `postrm` script.
- **Automated DEB Builder**: Created `scripts/sh/build_deb.sh` supporting version bumping (`major|minor|patch|none`), target architecture selection (`amd64`, `arm64`), release numbering (`-1`, `-2`), and local APT repository creation in `$HOME/randbotd-repo`.
