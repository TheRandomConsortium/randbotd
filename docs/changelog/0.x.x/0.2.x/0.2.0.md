# randbotd v0.2.0 Release Changelog

## 🏗️ NET-01 Cryptographic Core & Node Identity Engine

- **UDP Magic Bytes Inspector (`b"RBd1"`)**:
  - Implemented `RBd1` (`0x52, 0x42, 0x64, 0x31`) packet framing header inspector (`src/net/frame.rs`).
  - Incoming UDP packets not starting with `RBd1` are dropped immediately at the socket boundary.

- **Encrypted Ed25519 Node Identity & Memory Protection**:
  - Created `NodeIdentity` module (`src/crypto/identity.rs`) for Ed25519 keypair generation and verification.
  - Disk encryption via ChaCha20-Poly1305 + Argon2id saved to `./node_key.enc`.
  - In-memory private key bytes protected with `zeroize` zeroizing byte buffers.
  - Implemented master secret resolution hierarchy:
    1. `--masterpass <passphrase>` CLI argument / prompt (interactive mode).
    2. Linux Kernel Keyring (`keyctl search @u user randbotd_masterpass`) or systemd credentials (`/run/credentials/randbotd.service/masterpass`).
    3. `/etc/machine-id` fallback for unattended systemd daemon mode.

- **P2P Handshake Framing**:
  - Created `HandshakeInit` and `HandshakeAck` cryptographic serialization and signature verification (`src/net/handshake.rs`).
  - Supports signed X25519 ephemeral ECDH key agreement framing for session key derivation.

- **Live Project Gutenberg 256-Bit Mnemonic Engine ("Fuck BIP39")**:
  - Replaced static wordlist dictionaries with a live Project Gutenberg HTTP driller (`src/crypto/gutenberg.rs`).
  - Rolls cryptographic dices to drill down `https://www.gutenberg.org/dirs/` directory listings over HTTP, extracting random words from random books.
  - Records Gutenberg book URLs, word offsets, and words until $\ge 256$ bits of entropy are accumulated.

- **Economic Architecture & Anti-Fraud Game Theory**:
  - Documented Phase 9 Monero (XMR) Decentralized Market & Escrow-less Settlement Engine (`PAY-01` to `PAY-06`).
  - Defined Anti-Purge Fraud Game Theory (`Purge Cost = Remaining Prorated Fee - Reputational Cost Deduction`).
  - Added Heuristic Cluster Ponderation Penalties (`REP-07`) and Classical Attack Mitigation Matrix to `FUNCTIONALITIES.md` and `MANIFESTO.md`.
