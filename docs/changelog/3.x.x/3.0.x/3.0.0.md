# Changelog — randbotd 3.0.0

**Released:** 2026-08-18

## Summary

This major release transitions `randbotd` to **v3.0.0** due to breaking architectural changes separating static certificate parameters from CA declarations into structured **Multi-Tier CA Certificate Offer Catalogs & Profiles (`CA-12`)**.

> [!WARNING]
> ### ⚠️ Breaking Change & Local State Reset Notice
> As P2P consensus events are not yet emitted, no backward state migration is provided. Simply `rm -rf` previous `ca_declarations.json` or local state directory contents before launching v3.0.0.

---

## Breaking Changes & Enhancements

### 1. Multi-Tier CA Certificate Offer Catalog & Profile Engine (`CA-12`)

Previous versions attached a single static key algorithm and single validity TTL directly onto the `CaDeclaration`. Under `CA-12`:

- **Decoupled Architecture**: `CaDeclaration` defines the sovereign CA identity (Distinguished Name metadata, intermediate flags, path length constraints, overarching supported network capabilities, and draft status).
- **Certificate Offers (`CertificateOffer`)**: Specific issuance profiles (e.g. Clearnet tier, Tor Onion tier, short/micro-TTL, custom agility algorithms) are published as discrete offers tied to the CA via `ca_id`.
- **Offer Catalog (`CaOfferCatalog`)**: Groups active offers under a CA, computing a deterministic 32-byte hash `current_catalog_hash` referenced in `CaDeclaration` and stored in the dedicated `ca_offers.json` subtable.
- **Bidirectional Linking**:
  - `CertificateOffer` embeds `ca_id: [u8; 32]`.
  - `CaDeclaration` embeds `current_catalog_hash: Option<[u8; 32]>` and `offer_ids: Vec<u32>`.
  - `Database` provides queries for CAs and their associated offers/catalog.

### 2. IPC Protocol Updates

The local daemon IPC control protocol over Unix Domain Socket (`randbotd.sock`) has been updated:

- `PublishCa`: Creates and updates sovereign CA declarations.
- `PublishOffer`: Creates and updates certificate offers for a specified CA (`ca_id_hex`).
- `GetOffer`: Retrieves a specific offer by CA ID and offer ID.
- `ListOffers`: Lists all offers registered for a CA or across all local CAs.
