# Changelog — randbotd 3.3.0

**Released:** 2026-08-21

## Summary

This minor release implements **`CA-05` (Standard X.509 v3 Certificate Builder)** providing complete RFC 5280 ASN.1 DER and Base64 PEM certificate generation across all cryptographic key algorithms (Ed25519, ECDSA P-384, RSA-4096, ML-DSA-44 Post-Quantum Dilithium2). It introduces automatic Root CA self-signed certificate generation upon offer publishing, leaf domain certificate generation with coverage scope validation via an IPC testing endpoint, **`ENTROPY-01` (Configurable Plaintext Entropy Source URLs)** for dynamic operator-defined entropy sources, and modularizes the PKI cert subsystem into tidy submodules strictly adhering to codebase clutter limits.

---

## Key Features & Enhancements

### 1. Standard X.509 v3 Certificate Builder (`CA-05`)

- **RFC 5280 ASN.1 DER & PEM Encoders**:
  - Full DER encoding engine implemented for all X.509 v3 fields (`Version`, `CertificateSerialNumber`, `AlgorithmIdentifier`, `Issuer DN`, `Validity`, `Subject DN`, `SubjectPublicKeyInfo`, and `Extensions`).
  - Standard RFC 7468 PEM formatter (`-----BEGIN CERTIFICATE-----`).
- **Cryptographic Algorithm Agility**:
  - Supports signing and key encapsulation for Ed25519, ECDSA P-384, RSA-4096, and ML-DSA-44 (NIST FIPS 204 Dilithium2).
- **Standard & Custom Extension Support**:
  - `BasicConstraints` (`2.5.29.19`): `cA = true` (+ `pathLenConstraint`) for CAs; `cA = false` for leaf domain certificates (Critical).
  - `KeyUsage` (`2.5.29.15`): `keyCertSign | cRLSign | digitalSignature` for CAs; `digitalSignature | keyEncipherment` for leaf (Critical).
  - `ExtendedKeyUsage` (`2.5.29.37`): `serverAuth` (`1.3.6.1.5.5.7.3.1`) and `clientAuth` (`1.3.6.1.5.5.7.3.2`).
  - `SubjectAlternativeName` (`2.5.29.17`): DNS SANs autogenerated from coverage scopes or caller-specified.
  - `NameConstraints` (`2.5.29.30`): Subtree name constraint enforcement for Intermediate CAs (`CA-14`, Critical).
  - `AuthorityKeyIdentifier` (`2.5.29.35`) & `SubjectKeyIdentifier` (`2.5.29.14`): SHA-256 key identifier hashes.
  - `randbotd WoT Critical Extension` (`2.25.332006307751889903095271628869501346770.1.1`, `CA-10`): Marked Critical.
  - `Domain Proof Binding Extension` (`2.25.332006307751889903095271628869501346770.1.2`, `CA-03`).
- **Root CA Generation on Offer Publish**:
  - Publishing a certificate offer (`PublishOffer`) automatically constructs and signs the self-signed Root CA X.509 certificate.
- **Domain Certificate IPC Testing Endpoint**:
  - Added `IpcCommand::GenerateDomainCert` endpoint to issue, sign, and validate leaf domain certificates against CA capabilities, coverage scopes, and subtree name constraints.

### 2. Configurable Plaintext Entropy Source URLs (`ENTROPY-01`)

- **Configurable Plaintext URLs**: Added `[entropy] source_urls = [...]` in `randbotd.toml` and `--entropy-source-urls` CLI argument.
- **Content-Type & Non-Alphabetic Tokenizer**:
  - Strictly validates `Content-Type` headers: accepts `text/plain`, `text/csv`, `text/html`, `application/json`, `text/*`; strictly rejects `application/octet-stream`, `application/pdf`, multimedia, and binary payloads.
  - Tokenizes vocabulary across non-alphabetic boundaries, deduplicates distinct words, calculates true Shannon entropy ($H = \log_2(N)$), and CSPRNG samples words across iterations to derive 256-bit mnemonic seed entropy.
  - Gracefully falls back to Project Gutenberg directory drilling and embedded Crypto Anarchist Manifesto.

### 3. Modular Architecture & Strict Cleanliness

- **Decomposed PKI Cert Subsystem**:
  - Split `src/pki/cert.rs` into modular submodules under `src/pki/cert/` (`builder.rs`, `der.rs`, `extensions.rs`, `serial.rs`, `mod.rs`), ensuring every file is $\le$ 275 lines.
- **Dead Code Cleanup**:
  - Removed unused `#[allow(dead_code)]` suppressions in `src/pki/scope.rs`, `src/pki/ca.rs`, `src/crypto/gutenberg.rs`, and `src/pki/cert/serial.rs`, wiring all helper and validation methods into active daemon workflows.
- **Package Build & Release**:
  - Built and deployed Debian package `randbotd_3.3.0-1_amd64.deb` to local APT repository.
