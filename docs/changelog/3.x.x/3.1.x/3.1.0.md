# Changelog — randbotd 3.1.0

**Released:** 2026-08-19

## Summary

This minor release introduces **CA-13 (Cryptographic Certificate Serial Entropy Engine)** providing standard-compliant CSPRNG serial entropy for future X.509 certificate generation, alongside a modular refactoring of the daemon's IPC control handlers into domain-specific modules with dynamic registration.

---

## Key Features & Enhancements

### 1. Cryptographic Certificate Serial Entropy Engine (`CA-13`)

- **Standard-Compliant Serial Generation**: Implemented `CertificateSerialNumber` conforming to RFC 5280 §4.1.2.2 and CA/Browser Forum BR §7.1.4.2.1.
- **Configurable CSPRNG Entropy**: Generates between 64 and 160 bits (8 to 20 octets, default 20 bytes / 160 bits) of cryptographic entropy to prevent hash collision and serial prediction attacks.
- **Strict Positivity & ASN.1 DER Encoding**: Guarantees non-negative integer representation in accordance with RFC 5280, automatically prefixing leading `0x00` when the most significant bit is set (`to_der_integer_bytes()`).
- **Future Certificate Building Readiness**: Added warning documentation and active IPC diagnostic hooks ahead of full **`CA-05`** (X.509 Certificate Builder) integration.

### 2. Domain-Specific IPC Handler Refactoring

Decomposed monolithic IPC handler logic into clean, modular submodules:
- **`IpcHandler` Trait & `IpcHandlerRegistry`**: Dynamic dispatching framework supporting extensible handler registration (`src/net/ipc/handler/mod.rs`).
- **`PeerHandler`**: Manages peer network address imports into the local phonebook (`src/net/ipc/handler/peer.rs`).
- **`CaHandler`**: Manages CA declaration publication, drafts, metadata validation, and CA-13 entropy initialization (`src/net/ipc/handler/ca.rs`).
- **`OfferHandler`**: Manages certificate offer publishing, retrieval, and catalog queries (`src/net/ipc/handler/offer.rs`).
- **`ProofHandler`**: Manages domain proof challenge generation and multi-network verification (`src/net/ipc/handler/proof.rs`).
