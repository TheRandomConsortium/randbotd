# randbotd v1.4.2 Release Changelog

### 🔒 Active TLS ALPN & I2P SAM v3.0 Bridge Verification Implementation (`CA-03`)

Version 1.4.2 implements active network verification for **TLS ALPN (`randbotd-alpn/1`)** and **I2P SAM v3.0 STREAM Session (`port 7656`)** alongside the HTTP Nonce fallback engine.

---

## 🚀 Architectural Enhancements

### 1. TLS ALPN Verification (`fetch_tls_alpn_nonce`)
- **Protocol Identifier**: Sends ALPN token `"randbotd-alpn/1"` during TLS handshake over port 443.
- **Tor Proxy Integration**: Routes TLS ALPN requests for `.onion` domains through the configured Tor SOCKS proxy (`127.0.0.1:9050`).
- **Domain Proof Method**: Emits `DomainProofMethod::TlsAlpn` upon successful ALPN verification.

### 2. I2P SAM v3.0 Bridge Verification (`fetch_i2p_sam_nonce`)
- **SAM Bridge Socket Integration (`port 7656`)**: Connects directly to the I2P SAM bridge at `127.0.0.1:7656` (`config.privacy.i2p_sam_port`).
- **Handshake & Stream Session**:
  - Sends `HELLO VERSION MIN=3.0 MAX=3.1`.
  - Establishes a raw TCP `STREAM CONNECT ID=randbotd_verify DESTINATION=<domain> PORT=80`.
  - Transmits HTTP GET request over the SAM STREAM session to fetch `http://<domain>/.well-known/randbotd-proof`.
- **Domain Proof Method**: Emits `DomainProofMethod::I2pSamBridge` upon successful SAM stream verification.
