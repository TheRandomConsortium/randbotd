# Changelog — randbotd 4.0.0

**Released:** 2026-09-23

## Summary

This major release introduces **CA-06: CA Command Center Dashboard** and advances **ECO-03: `randbotctl` CLI & CA Command Center** to 🟡 In Progress, establishing an operator control plane and dedicated interactive CLI binary:

1. **Dedicated Standalone `randbotctl` Binary**: Cleanly splits the interactive operator interface from the background protocol daemon `randbotd`. Installs both `/usr/bin/randbotd` and `/usr/bin/randbotctl` via Debian packages with human-friendly colored tables and `--json` support for automation.
2. **Localhost CA Command Center Dashboard (`CA-06`)**: An interactive localhost web control plane (`http://127.0.0.1:43211`) launched on-demand via `randbotctl dashboard`, featuring live health indicators, an interactive Swarm Bid Curve chart (`CA-05`/`CA-11`), and quick actions for certificate revocations and domain purges with zero external web dependencies.
3. **Automated Domain Certificate Revocation on Purge (Breaking Contract Update)**: Tying `CA-07` domain purges directly to CRL management. Emitting a bad-domain purge now automatically revokes all certificates previously issued to that domain under the purging CA, placing them onto the CA's CRL with revocation reason `privilegeWithdrawn` (code 9) to protect both P2P WoT peers and legacy X.509 verifiers.
4. **Expanded IPC Control Plane**: Added new commands for listing CAs (`ListCas`), inspecting individual CAs (`GetCa`), node status metrics (`GetNodeStatus`), peer inspection (`ListPeers`), and individual certificate revocation (`RevokeCert`).

## ⚠️ Breaking Contract & Architectural Rationale for Major Version Bump (4.0.0)

This release applies a **Major** SemVer bump (`3.7.1` $\rightarrow$ `4.0.0`) due to two fundamental architectural and behavioral contract changes:

1. **Purge-to-CRL Operational Contract Mutation (`CA-07` $\rightarrow$ `CRL`)**:
   - *Previous Contract (v3.x)*: Emitting a domain purge (`IpcCommand::PurgeDomain`) was strictly a Web-of-Trust (UTW) reputation event. The issuing CA's Certificate Revocation List (CRL) remained completely decoupled and untouched.
   - *Breaking Change (v4.0.0)*: The operational contract now enforces cryptographic consistency. When a CA purges a domain, the daemon automatically queries all issued certificate chains, identifies every active certificate assigned to that domain, and mutates the CA's CRL to revoke them under reason `privilegeWithdrawn` (code 9). This mutates CRL state, increments the CA's `crl_number`, and triggers automated CRL broadcast events across the P2P gossip network. Systems or scripts assuming domain purges do not alter standard X.509 CRL states will encounter state and sequence divergence.
2. **Binary Decoupling & Package Topology Split**:
   - Interactive operator tools and web dashboard hosting have been severed from `randbotd` and re-homed into a separate standalone binary: `randbotctl`.
   - The crate structure was promoted to a dual-binary topology (`randbotd` daemon + `randbotctl` operator CLI) backed by a core library target. Distributions and system integrations must now install and interface with `randbotctl` for interactive control rather than invoking the daemon directly.

## Key Changes & Enhancements

### 1. Dedicated `randbotctl` CLI Binary (`src/cli/`)
- **Binary Architecture**:
  - Modularized CLI operations into `src/cli/` with `main_ctl.rs`, `client.rs`, `format.rs`, `dashboard.rs`, `web_assets.rs`, and `daemon.rs`.
  - Defined `randbotd` as a library crate in `src/lib.rs` alongside dual binary targets (`randbotd` and `randbotctl`).
- **Command Suite**:
  - `randbotctl status`: Displays node pubkey, connected peers, and summary counts of CAs, offers, certs, CRLs, and purges.
  - `randbotctl ca list` / `get` / `publish`: Manage and inspect Root and Intermediate CAs.
  - `randbotctl offer list`: Inspect certificate offer profiles.
  - `randbotctl cert revoke`: High-level certificate revocation by serial number.
  - `randbotctl purge emit` / `list` / `get`: Emit bad-domain UTW purges with PoW difficulty scaling.
  - `randbotctl peer list` / `import`: Manage P2P overlay peers.
  - `randbotctl swarm list`: Inspect active threshold custodian contracts.
  - `randbotctl dashboard`: Launches the embedded localhost web dashboard.

### 2. CA Command Center Dashboard (`CA-06`)
- **Interactive Control Plane**:
  - Built with a sleek cypherpunk dark theme, responsive metric grid, and real-time auto-refreshing stats.
  - Interactive SVG Swarm Bid Curve plotting incumbent custodian revenue-share percentages against candidate under-bids.
  - One-click certificate revocation and domain purge forms with real-time feedback.

### 3. IPC & Storage Layer Extensions
- **`CaHandler`**:
  - Implemented `ListCas` and `GetCa` commands, returning structured JSON including top-level `ca_id_hex`.
- **`PeerHandler`**:
  - Implemented `GetNodeStatus` and `ListPeers` commands, returning peer connections and subtable entity counters.
- **`CrlHandler`**:
  - Implemented `RevokeCert` command, automatically retrieving the active CRL, appending the revoked serial with revocation reason, incrementing CRL sequence number, and updating the database.
- **`PurgeHandler`**:
  - Updated `handle_purge_domain` to query issued certificate chains and automatically register matching domain certs as revoked on the issuing CA's CRL.
